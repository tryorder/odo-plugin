TryOrder

Two-way integration between Odoo and the TryOrder ordering platform

TryOrder turns your Odoo instance into a first-class channel for the TryOrder platform. Your Odoo products and POS branches flow out to TryOrder, and orders placed on TryOrder flow back into Odoo Point of Sale - with prices, discounts, notes, payment type and live status kept in sync both ways.

Requires a TryOrder account. This module is the Odoo side of the integration and does nothing on its own.

What it does

Menu & catalog sync

  • Exports POS categories, products, variants, modifiers and combos.
  • Branch-aware: each mapped POS (pos.config) receives only its own products, honoring company and Limit Categories settings.
  • Multilingual names (English / Arabic) and product images.

Order sync

  • Creates a real pos.order so orders appear in Point of Sale.
  • Line-level notes, order notes, order type and payment method (cash/card).
  • Itemized discounts as their own lines: Coupon, Wallet, Loyalty Points.
  • Free-product coupons sync at price 0.

Live status, both ways

  • Status pushed from TryOrder is shown as a colored badge on the order.
  • Odoo state changes (paid / done / cancelled) are pushed back to TryOrder via a non-blocking post-commit webhook.

Built-in observability

  • Every inbound API call and outbound webhook is recorded in a log you can browse inside Odoo.
  • API-key protected endpoints; no external OCA dependency required.

HTTP API

All endpoints are protected by a shared API key sent in the X-Api-Key header (configured under Settings › Order Connector).

GET  /order_connector/ping                    health / credential check
GET  /order_connector/branches                list POS branches (pos.config)
GET  /order_connector/catalog?branch_id=..    branch-specific menu
POST /order_connector/orders                  create an order in Odoo
PUT  /order_connector/orders/<id>/status      update / cancel an order

Setup

  1. Install the module.
  2. Open Settings › Order Connector and set your API key (shared with TryOrder).
  3. In TryOrder, connect the Odoo account and map each branch to a POS.
  4. Sync the menu and start receiving orders.

Compatible with Odoo 18 Community. Depends only on standard modules (Point of Sale, Sales).
